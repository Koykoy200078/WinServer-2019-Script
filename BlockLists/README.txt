# Master Block List Configuration
# This file loads all block lists from the BlockLists folder
# Edit individual category files to customize blocking

# Categories:
# - social-media.txt: Facebook, Instagram, Twitter, TikTok, etc.
# - video-sites.txt: YouTube, Netflix, Twitch, etc.
# - gaming-sites.txt: Roblox, Steam, online game sites, etc.
# - ai-sites.txt: ChatGPT, Claude, Bard, AI tools, etc.
# - shopping-entertainment.txt: Amazon, eBay, Spotify, etc.

# To add more sites:
# 1. Open the appropriate category file in BlockLists folder
# 2. Add the domain (one per line)
# 3. Save the file
# 4. Run the block command again

# To create a new category:
# 1. Create a new .txt file in BlockLists folder
# 2. Add domains (one per line)
# 3. The script will automatically load it
