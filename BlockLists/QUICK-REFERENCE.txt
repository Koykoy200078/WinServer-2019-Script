# ==================================================================

🎯 HOW IT WORKS:
----------------
1. Run AA.ps1 from Desktop
2. Script automatically loads ALL .txt files from BlockLists folder
3. Ignores comment lines (starting with #)
4. Blocks all sites by redirecting to 127.0.0.1

# ==================================================================

✏️ HOW TO EDIT BLOCK LISTS:
---------------------------

METHOD 1 - Add individual sites:
  1. Open the category file (e.g., social-media.txt)
  2. Add domain at the end:
     newsite.com
     www.newsite.com
  3. Save file
  4. Run AA.ps1 again

METHOD 2 - Remove sites:
  1. Open the category file
  2. Delete the line with unwanted domain
  3. Save file

METHOD 3 - Add comments:
  1. Lines starting with # are ignored
  2. Use for organization:
     # Major platforms
     facebook.com
     instagram.com

METHOD 4 - Disable entire category:
  1. Rename file: social-media.txt → social-media.txt.disabled
  2. Script will skip it

🛠️ ADVANCED CUSTOMIZATION:
---------------------------

Create custom category:
  1. Create new file: custom-sites.txt
  2. Add domains (one per line)
  3. Script auto-loads it

Example custom-sites.txt:
  # My Custom Blocks
  example.com
  www.example.com
  badsite.net
  www.badsite.net

# ==================================================================

🚀 QUICK COMMANDS:
------------------

View all block lists:
  Right-click View-BlockLists.ps1 → Run with PowerShell

Count total sites:
  (Get-ChildItem BlockLists\*.txt | Get-Content).Count

Find specific site:
  Select-String -Path BlockLists\*.txt -Pattern "facebook"

# ==================================================================

💡 TIPS:
--------
• Always include both www and non-www versions
• Add one domain per line
• No http:// or https:// needed
• Comment lines start with #
• Empty lines are ignored
• Case-insensitive
