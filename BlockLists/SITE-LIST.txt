HOW TO USE:
-----------
1. Run AA.ps1 script
2. The script automatically loads ALL sites from these files
3. Choose options 8-13 to block/unblock PCs

HOW TO CUSTOMIZE:
-----------------
1. Open any category file (e.g., social-media.txt)
2. Add new sites (one domain per line)
3. Lines starting with # are comments (ignored)
4. Save the file
5. Run the script again

EXAMPLE - Adding a new site:
----------------------------
Open social-media.txt and add:
mynewsite.com
www.mynewsite.com

HOW TO CREATE NEW CATEGORY:
----------------------------
1. Create a new .txt file (e.g., news-sites.txt)
2. Add domains (one per line)
3. Script will automatically load it

DISABLE A CATEGORY TEMPORARILY:
-------------------------------
Rename the file extension:
social-media.txt → social-media.txt.disabled
